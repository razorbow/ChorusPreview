# Chorus Preview — Fabric 1.21.11

Автор: **razorbow**.

Клиентский мод показывает цветные области, куда может телепортировать обычный хорус, и оценку шанса успешной телепортации после 16 попыток.

## Установка

Помести `chorus-preview-1.2.2-mc1.21.11.jar` в `mods`. Нужны Minecraft 1.21.11, Java 21, Fabric Loader 0.18.4+ и Fabric API для 1.21.11. Mod Menu 17.0.0 нужен для удобного меню настроек, но не обязателен.

Подсветка появляется только когда обычный хорус находится в основной или второй руке. Клавиша H включает и выключает мод.

## Что учитывается

- Реальный хитбокс текущей позы: примерно 1,8 блока стоя, 1,5 присев и 0,6 при ползании.
- Дробные X/Y/Z, диапазон диаметром 16 блоков, ограничение Y высотой измерения и 16 последовательных попыток.
- Поиск ближайшего вниз блока с `blocksMotion`, как в `LivingEntity.randomTeleport`.
- Полные и неполные коллизии, люки, плиты, лестницы, заборы, сущности, граница мира и любые жидкости внутри хитбокса.
- Если нужный чанк не загружен на клиенте или расчёт ограничен защитным лимитом, процент не выдаётся как точный.

Настройки: отдельные поля R/G/B (0–255), прозрачность кнопками −/+ (0–100%),
видимость через стены, HUD, частота обновления и бюджет расчёта на тик.
Есть три режима плоских меток: заливка, контур и оба одновременно. Каждая метка
имеет одинаковый размер 0,62 блока и располагается по центру верхней грани.
Для HUD можно включить компактный режим «Только шанс», скрывающий хитбокс и подсказки.
0% прозрачности — непрозрачные, 100% — невидимые.
Старый цвет и альфа сохраняются; старый параметр volumes больше не влияет на рендер.
Интерфейс полностью переведён на русский и английский.

## Ограничения

Это предсказание по известному клиенту состоянию мира, а не знание случайных чисел сервера. Оно показывает все рассчитанные допустимые области и вероятность успеха, но не может заранее назвать одну фактическую точку. Движение сущностей, открытие люков, изменение позы, выгрузка чанка или серверные плагины между расчётом и окончанием еды могут изменить результат.

Мод не отправляет пакеты и не меняет механику телепортации.

## Проверка сборки 1.2.1

- Компиляция Java 21 против Minecraft 1.21.11 и Fabric API 0.141.6+1.21.11 прошла без ошибок.
- Итоговый JAR преобразован в intermediary mappings, его структура и метаданные проверены.
- Все тесты геометрии, формулы 16 попыток, ограничения высоты мира и хитбоксов поз прошли.
- Наборы ключей русского и английского переводов совпадают; новые строки присутствуют в обоих языках.
- Запуск клиента в этой среде остановился на скачивании игровых ресурсов, поэтому визуальную проверку нужно выполнить в игре.
